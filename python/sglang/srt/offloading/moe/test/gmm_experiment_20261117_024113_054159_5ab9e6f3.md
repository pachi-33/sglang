## 实验目的与控制变量

比较相同计算规格下，连续专家槽位的 type1 与间隔专家槽位的 type2。两组使用同一批输入和逻辑专家权重，并保持 token 分布、权重池大小、量化参数、INT8 输入/权重、NZ 权重格式和 BF16 输出一致。

| Case | 活跃专家物理槽位 | group_list |
| --- | --- | --- |
| type1_contiguous | 0, 1, …, E−1 | S 个 count，未使用尾部为 0 |
| type2_sparse_slots | 0, stride, …, (E−1)×stride | S×2 的 (slot, count)，尾部为 0 |

E 为活跃专家数，S = E × slot_stride。这里的稀疏指槽位间隔。实验同时改变槽位布局和 group_list_type，结果不能单独归因于 type 字段。

## 本次测量结论

type2/type1 中位耗时比为 **0.9895**。在本次配置下，type2 的中位耗时比 type1 低 **1.05%**。该结果仅描述本次测量。

## 计时口径与范围

预热后按 AB/BA 顺序交替测量；每轮耗时除以 iterations，得到每个 GMM 的平均耗时。表中的中位值、最小值、最大值来自这些轮平均值，不是单次调用的延迟分位数。

graph 模式计时已捕获的多次 GMM 回放；eager 模式计时普通调用，可能包含下发不足导致的设备空闲。数据准备、H2D、格式转换、路由、预取和图捕获不计时。权重重复使用，因此结果反映稳态 GMM，不代表冷缓存或完整 FFN/推理性能。
