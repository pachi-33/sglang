The memory fields belong to the last request because the backend resets PyTorch
peak counters for each generation. That prompt retokenized to 988 tokens, so its
1.18 GiB total-memory minus peak-reserved margin is not a 2048-token acceptance
result. Free memory after reset was 1,015,021,568 bytes.

This host exposes the RTX 4070 SUPER through PCIe width x1 even though the device
supports x16. The idle link generation sampled after the run was Gen1 and its
maximum is Gen4; the width remained x1. The 3584 MiB cache also holds half as many
experts as the V100 7168 MiB profile, and the run recorded 2.03 times the V100
pack reads/H2D. These factors materially confound the comparison; it must not be
treated as representative 4070 SUPER Gen4 x16 performance or as an SLA.
